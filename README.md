### [CRUDify](https://github.com/mite-404/crudify)
A configurable CRUD generator for **NestJS** and **Mongoose**. You write the model, service and controller — Crudify generates the routes and the repetitive CRUD logic: a complete set of REST endpoints, Swagger docs, runtime route enable/disable, soft deletes, bulk operations, advanced query parsing, and optional MongoDB-backed audit logging.
